\section{関連研究}
\label{sec:related}

Dongら\cite{dong2019}は，NVDのエントリとCVE概要文・参照先の非構造なレポートとの不整合を検出するシステムVIEMを提案し，約20年分・78,296件のCVE IDを対象とした調査で，NVDエントリと影響バージョンが完全に一致するのは59.82\%にすぎないことを示した．

本研究はDongらと問題意識を共有するが，VIEMがNVDにエントリが存在することを前提に不整合を測るのに対し，本稿はCVE増加後に顕在化した\textbf{検知条件がそもそも生成されない}という失敗モード（\texttt{Deferred}）を対象とし，検知精度への影響まで評価する点で異なる．また抽出精度単体ではなく\textbf{継続運用における保守性・再現性}を設計目標に置く．

NVDのデータ品質については，Anwarら\cite{anwar2022}が公開日・ベンダ名・深刻度等の不整合と欠損を体系的に調査し，NguyenとMassacci\cite{nguyen2013}がGoogle Chromeを対象に影響バージョンデータの系統的な誤りを示している．
いずれもCVE増加以前の調査であり，本稿は同種の問題が2024年以降に「欠損」として急拡大したことを示す点で相補的である．
